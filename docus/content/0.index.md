#title
Easily build reliable distributed applications

#description
MassTransit provides a developer-focused, modern application stack for building distributed systems without the complexity.

#extra
  ::list{type="success"}
  - First class testing support
  - Write once, deploy using RabbitMQ, Azure Service Bus, and Amazon SQS
  - Observability via Open Telemetry (OTEL)
  - Fully-supported, widely adopted, a complete end-to-end solution
  ::
::
